## Network-to-neural mapping

| Networking concept | Neuro-OSI equivalent |
|---|---|
| MAC address | **NDID**: Neural Device ID, hardware identifier of an implant |
| IP address | **NID**: Neural ID, address of a mind on the network |
| TCP | Reliable thought transport (facts, instructions, skills) |
| UDP / RTP | Streaming transport (emotions, sensations, AR) |
| TCP receive window | **Cognitive window**: how much the receiver can absorb right now |
| TLS handshake | **Telepathic handshake**: authentication + consent |
| Codec | **Neural codec**: translation between brain-specific code and shared semantic space |
| NGFW | **Neural NGFW**: cognitive firewall for incoming thoughts |
| DLP | **Neural DLP**: prevention of thought leakage |
| IPS | **Anti-injection**: protection against imposed thoughts |
| Sandbox detonation | **Digital-twin detonation**: testing a thought on a model of the user's brain |
| UEBA | **Behavioral baseline** of a person's neural activity |
| DDoS | **Cognitive DDoS**: flooding a brain with signals |
| CVE | **Neuro-CVE**: registry of neural-technology vulnerabilities |
| SOC | **Neuro-SOC**: neural security operations center |

## Terms

**AI Guardian**: An on-device AI layer that detects novel threats by behavior and effect rather than signatures. It may strengthen but never weaken hard rules.

**Brainjacking**: Unauthorized control over a brain implant or over the content delivered through it.

**Consciousness sandbox**: Presentation of an incoming thought as a clearly marked message, so the person decides whether to integrate it.

**Intent gating ("push-to-think")**: Transmission only of content confirmed by a conscious act of will.

**Intensity clamping**: Hardware limit on emotional or sensory amplitude.

**Neurorights**: Proposed human rights protecting mental privacy, mental integrity, cognitive liberty and psychological continuity.

**`ORIGIN_TAG`**: Mandatory packet field marking a thought as foreign; preserved all the way to conscious perception.

**`PERCEPT_OVERLAY`**: Packet type for augmented-reality content, with spatial anchoring and opacity limits.

**Reality integrity check**: AI comparison of sensor data with AR overlays to detect reality spoofing.

**Recall buffer**: Short delay before transmission during which sending can be cancelled.

**Side-channel probing**: Extracting private information by presenting stimuli and measuring involuntary brain responses (for example, P300).

**Watcher of the watcher**: A simple deterministic module that verifies the integrity of the AI Guardian.
